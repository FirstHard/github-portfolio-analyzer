# GitHub Portfolio Analyzer

A full-stack web application that analyzes GitHub user profiles and provides insights based on repository data.

## 🚀 Features
- GitHub API integration
- Profile analysis & scoring system
- Configurable scoring via .env
- Google reCAPTCHA protection
- Data visualization (Chart.js)
- Rate limiting & caching
- Clean REST API (Laravel)
- Angular frontend (SPA)

## 🛠 Tech Stack
- Backend: Laravel
- Frontend: Angular + Tailwind CSS
- Charts: Chart.js
- API: GitHub API
- Security: Google reCAPTCHA
- DevOps: Docker
